# THE 24th — A little universe, made just for you

A private, mobile-friendly birthday experience for 24 November 2026.

## What's inside
- A midnight-blue, champagne-gold cinematic opening with a dimensional gift reveal.
- A warm ivory keepsake-paper chapter with an interactive friendship constellation.
- An envelope interaction and the complete original birthday letter.
- A memory timeline, a small three-digit memory vault, and a multi-burst fireworks finale.
- The supplied `A Thousand Years (Instrumental)` MP3, with a user-initiated start, fade-in/out, pause control, and looping playback.

## Open on your Mac
1. Extract this ZIP into a new folder.
2. Open the `THE-24TH` folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension, or double-click `index.html` to preview it in a browser.
4. On the first screen, tap the gift. This starts the music after a user interaction, as required by modern browsers.

## Personal details
- Birthday: 24 November 2026
- Recipient: My Bestie
- Secret code: `208` (the clue points to 2008)

You can change these in `js/config.js`.

## Music
The supplied MP3 is stored at `assets/music/a-thousand-years-instrumental.mp3`. Keep that file in place so the relative audio path continues to work. The track starts only after the visitor taps the gift or music button.

## Publish privately
You can publish the folder using GitHub Pages or another static hosting service and share the URL. Note that a static website URL is not password-protected: anyone with the link may open it. The vault is a playful birthday puzzle, not real access control.
